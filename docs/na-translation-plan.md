# NA Translation Plan

- Home
- About

- Services
- News
- Directory

## Approach
1. Create NA route structure under /na/
2. Translate shared nav labels and CTAs

5. Verify build after each batch

- No broken links
- No placeholder English in translated NA main pages
- Homepage hero, quick access, services, news, about, directory, contact translated
- Build passes
